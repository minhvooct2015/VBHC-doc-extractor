3. Tạo systemd service (venv ngoài repo)
File /etc/systemd/system/vbhc_ocr.service:

sudo nano /etc/systemd/system/vbhc_ocr.service
                  
[Unit]
Description=VBHC OCR FastAPI service
After=network.target

[Service]
User=vanban
WorkingDirectory=/home/vanban/VBHC-doc-extractor
Environment="PATH=/home/vanban/myenv/bin:/usr/bin"
ExecStart=/home/vanban/myenv/bin/uvicorn app:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Sau đó:
sudo systemctl daemon-reload
sudo systemctl enable vbhc_ocr
sudo systemctl start vbhc_ocr
sudo systemctl status vbhc_ocr


# Xem trạng thái
sudo systemctl status vbhc_ocr

# Restart khi đổi code / model
sudo systemctl restart vbhc_ocr

# Dừng service
sudo systemctl stop vbhc_ocr
